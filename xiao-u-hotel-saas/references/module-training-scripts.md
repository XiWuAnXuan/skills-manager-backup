# Training Script Module

## Default Demo Order

Use this sequence for live training or sales/demo scripts:

1. 看房态.
2. 办入住.
3. 住中服务.
4. 退房结算.
5. 房务打扫.
6. 数据管理和运营扩展.

## Voice

Use a clear spoken training style, but keep documents polished:

- "大家先看这个房态图..."
- "前台办理前先确认..."
- "这个地方重点看金额和支付方式..."
- "大家可以实操练习一下..."

## Training Blocks

For each block, include:

- Scene: who is operating and why.
- Before-click check: amount, room, identity, customer type, permission.
- Operation steps.
- Result after operation.
- Practice task.
- Common mistakes.

## Common Practice Tasks

- Open a room for an individual guest.
- Add a room consumption item.
- Supplement deposit.
- Change room.
- Convert reservation to check-in.
- Checkout with insufficient deposit.
- Handle agreement/OTA posting.
- Add restaurant order and settle.
