# 门锁卡片管理软件界面模板（云店掌门锁风格）

## Overview

提供一套**经过实测验证的门锁制卡软件界面规范**（源自"云店掌门锁系统"pms_interface.exe），当用户需要为其他门锁接口（汉庭/创新佳/同创/其他锁厂）制作同风格制卡软件时，按本规范复现界面：**顶部正在开的房间大字 + 中部卡片失效时间 + 底部三按钮**，简洁、美观、前台可快速操作。

## 界面结构（三区块布局）

```
┌────────────────────────────────────┐ 窗口 480×260, FixedSingle, 不可最大化
│  ┌──────────────────────────────┐  │
│  │   正在开：8201房间            │  │ ← ① 顶部房间大字 (46px高, 浅蓝底)
│  └──────────────────────────────┘  │
│  卡片失效时间                       │ ← ② 中部: 小标签
│  ┌──────────────────────┐ ┌──┐   │
│  │ 2026-08-07 12:00    │ │📅│   │   掩码输入框(410宽,15号字居中) + 日历按钮(40宽)
│  └──────────────────────┘ └──┘   │
│  [ 读卡 ]   [ 开新卡 ]  [ 注销卡 ] │ ← ③ 底部三按钮 (各140×52)
└────────────────────────────────────┘
```

## 交互规则（必须一致）

1. **开新卡**：成功 → `MessageBox` 弹窗"XXX房间开卡成功" → 点确定**自动关闭窗口**；失败弹窗显示明确原因（无卡/密码错误/串口…）。
2. **读卡**：弹窗显示卡完整信息（所属房间/卡型/起始/失效时间）；**返回码 7（新卡）是正常状态**，提示"这是一张新卡（空白卡）"，不当失败。
3. **注销卡**：成功弹窗"该卡为空卡/新卡状态"；新卡提示"本来就是新卡，无需注销"。
4. **多房间批量**：单窗口内队列，开卡成功自动切换下一间（顶部变"正在开：8202房间(2/3)"），全部完成自动 `Close()`。
5. **读卡/注销操作模式**（PMS 下发无房间号的读卡/注销指令）：顶部显示"请进行XX操作"、隐藏时间输入区、禁用开新卡按钮。
6. **界面保持极简**：不要加日志框/状态栏（如需排错日志写入文件）；不加全屏独占/键盘锁定（用户明确反对过）；三按钮是唯一操作入口。

## 复用步骤（为新锁厂做同风格界面）

1. 保留窗体参数、三区块布局、配色、字体（照抄本规范的参数表）。
2. 替换业务：`BuildUi` 代码模板不变，只改三处——锁厂 SDK 调用（`LockSdk` 换成新 DLL 封装）、指令解析（`PmsCommand` 按新 PMS/协议）、映射表（`LockRoom` 按需）。
3. 编译：C# WinForms，`/platform:x86`（32 位锁厂 DLL），源码 UTF-8 BOM + `/codepage:65001`，`build.bat` 必须**纯 ASCII**（中文会导致 cmd 乱码）。
4. 按钮文案可换：主操作按钮用蓝色 Bold、次操作用灰蓝、危险/完结操作用橙色——保持三色语义即可。
