# 界面布局与配色详细规格（云店掌门锁风格）

> 本文件是 `SKILL.md` 的补充：给出**每个控件的确切坐标/尺寸/颜色值**，供复现时逐项对照。任何值都不要随意改——这套参数是实测打磨过的，改动会破坏简洁感和易用性。

## 1. 窗体规格

| 属性 | 值 | 说明 |
|---|---|---|
| ClientSize | 480 × 260 | 固定尺寸，不随分辨率缩放 |
| Font | Microsoft YaHei UI 10F | 全局默认字体（微软雅黑） |
| FormBorderStyle | FixedSingle | 固定边框，不可拉伸 |
| MaximizeBox | false | 禁止最大化（前台操作员不需要） |
| MinimizeBox | 默认 true | 保留（可暂时最小化） |
| StartPosition | CenterScreen | 居中显示 |
| ShowInTaskbar | 默认 true | 任务栏可见，便于识别 |

## 2. 控件坐标总表（窗体坐标原点=左上角）

| 控件 | Location | Size | 说明 |

| lblExpire 标签 | (12, 88) | AutoSize | "卡片失效时间" |

**布局要点**：
- 三按钮 y=178 + 高52 = 底边 230，窗体高 260 → 底部留白 30px，视觉平衡。
- 输入框 410 + 日历按钮 40 = 450 + 左距12 = 462，窗体宽 480 → 右侧留白 18px。
- 水平方向全部 `startX=12`，统一对齐。

## 3. 配色方案（Color.FromArgb）

| 用途 | RGB | 色名 | 应用 |
|---|---|---|---|
| 房间大字文字 | (24, 90, 160) | 深蓝 | 顶部横幅文字 |
| 房间大字背景 | (230, 241, 251) | 浅蓝 | 顶部横幅底色 |
| 操作模式背景 | (241, 239, 232) | 浅灰 | 读卡/注销操作时横幅底色 |
| 标签文字 | DimGray | 灰 | 失效时间标签 |
| 日历按钮底 | (108, 117, 125) | 中灰 | 📅 按钮 |
| 读卡按钮底 | (96, 125, 139) | 蓝灰 | 次要操作 |
| 开新卡按钮底 | (52, 120, 246) | **亮蓝** | 主操作（Bold） |
| 注销卡按钮底 | (230, 126, 34) | **橙** | 完结/危险操作 |
| 按钮文字 | White | 白 | 全部按钮统一 |

**三色语义**（可推广到任何门锁系统）：
- **蓝（主操作）** = 制卡/发卡——最常用的动作，视觉最突出
- **橙（完结操作）** = 注销/退房——不可逆、需谨慎
- **灰蓝（查询操作）** = 读卡/查询——中性

## 5. 界面行为规格

### 5.1 三种界面状态
| 状态 | 房间大字 | 时间区 | 开新卡按钮 |
|---|---|---|---|
| 等待中 | "等待开卡指令…"（浅蓝底） | 可见 | 可用 |
| 制卡任务 | "正在开：8201房间(2/3)"（浅蓝底） | 可见（已预填） | 可用 |
| 读卡/注销操作 | "请进行读卡操作"（浅灰底） | **隐藏** | **禁用** |

### 5.2 交互反馈规则
- **开新卡成功** → 弹窗"8201房间开卡成功"（Info）→ 确定后 `Close()` 自动关窗。
- **开新卡失败** → 弹窗"8201房间开卡失败：{原因}"（Error），不关窗可重试。
- **读卡成功** → 弹窗显示：所属房间 / 卡片类型 / 起始时间 / 失效时间。
- **读卡新卡(7)** → 弹窗"这是一张新卡（空白卡）"（Info）——**不是失败**。
- **注销成功** → 弹窗"卡片已注销，该卡为空卡/新卡状态"。
- **注销遇到新卡** → 弹窗"该卡本来就是新卡，无需注销"。

### 5.3 多房间连续开卡
```
PMS 下发 3 间 → 弹第 1 间窗口(正在开：8201房间)
  → 开卡成功 → 弹窗确认 → 自动关闭
  → 自动弹第 2 间(正在开：8202房间) ... 直到全部完成自动退出
```
实现方式：`Program.cs` 解析任务列表后 `foreach (var t in tasks) Application.Run(new MainForm(t))`，窗口 `FormClosed` 后循环自然进入下一间。或单窗口内队列 + `LoadTask(_queueIndex + 1)`（推荐，支持方案B重复开卡更新）。

## 7. 复用时唯一需要改动的三处业务

| 位置 | 说明 |
|---|---|
| 锁厂 SDK 调用 | `LockSdk.cs` → 换成新 DLL（DllImport + StdCall + StringBuilder） |
| 指令解析 | `PmsCommand.ParseTasks` → 按新 PMS 协议解析房号/时间/action |
| 映射表 | `LockRoom` → lock_room.txt 或按新锁厂规则 |

界面层（BuildUi/日历弹窗/按钮事件）**完全复用，零改动**。
